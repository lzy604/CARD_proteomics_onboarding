# Universal contaminants FASTA

`Universal_Contaminants_381.fasta` contains **381 contaminant protein entries**. It is the supplemental contaminant FASTA from Frankenfield et al. (2022), copied from the supplied `NIHMS1873978-supplement-Contaminant_FASTA.txt` file.

The entries use the `Cont_` prefix in their FASTA identifiers, which makes them easy to recognize and filter during downstream review.
