# Editing and publishing the handbook

Edit the `.Rmd` files in this folder. Then, from R or RStudio, run:

```r
rmarkdown::render_site()
```

This writes the HTML website to the repository's `docs/` folder. GitHub Pages can be configured to publish from the `main` branch and `/docs` folder.

Do not upload raw mass-spectrometry files to this repository. Link to approved shared storage instead.
